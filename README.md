# Mobile Sales Performance & Data Analytics Dashboard

## Project Overview
This interactive Power BI project analyzes mobile phone sales performance, payment preferences, regional distribution, and customer ratings across India. It unifies scattered operational metrics into a single executive dashboard to support data-driven decision-making.

## Business Problem Solved
Retail businesses often face challenges tracking regional market demand, product mix performance, and customer payment behaviors across multiple retail hubs. This dashboard addresses these issues by providing:
* **Geographic Market Visibility:** Mapping sales concentrations across major Indian hubs (e.g., Delhi, Mumbai, Bangalore) to guide regional expansion.
* **Product & Brand Mix Optimization:** Evaluating revenue and units sold for top brands (Apple, Samsung, Xiaomi, Vivo, OnePlus) to optimize inventory allocation.
* **Customer Behavior Tracking:** Tracking adoption rates across payment channels (UPI, Credit/Debit Cards, Cash) and monitoring 1–5 star customer rating distributions.

## Key Insights & Metrics
* **Total Revenue:** $114M generated across all mobile sales.
* **Total Units Sold:** ~3K units.
* **Total Transactions:** 549 transactions.
* **Average Order Value:** $41K per transaction.
* **Payment Method Breakdown:** High adoption of digital payment methods (UPI and Credit Cards) relative to cash transactions.
* **Sales Seasonality:** Monthly trends show sales volume peaks in mid-year promotional months (May and July).

* **Power BI Desktop:** Data modeling, DAX queries, and dashboard layout design.
* **Microsoft Excel / CSV:** Data source file storage.
* **GitHub:** Version control and portfolio presentation.

## How to View & Use
1. Download or clone this repository.
2. Open `Mobile_Sales_Dashboard.pbix` in **Power BI Desktop**.
3. Use the left-side slicers to filter data dynamically by month, mobile brand, payment method, or day.
